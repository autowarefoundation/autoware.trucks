# Autoware - Autonomous Highway Trucking

</div>

The goal for this effort in Autoware is to build an open-source highway autonomy trucking system that can power safe autonomous driving around the world. We start with an SAE Level 2+ highway pilot and work toward SAE Level 4. To learn more about how to participate in this project, please read the [onboarding guide](/ONBOARDING.md).

## Vision: Bridge the Gap

Heavy-duty trucks differ from passenger vehicles in vehicle structure, use cases and operational demands. The Autoware Truck Working Group aims to bridge the gap between the latest autonomous driving research and the real-world needs of highway trucking, by building and validating open-source autonomous trucking software together with the Autoware Foundation.

## Scope

The working group focuses on autonomous trucking software built with the Autoware Foundation (AWF). Our work covers:

- **Reference design**: Provide a reference design for autonomous highway trucks, including the hardware, the software architecture and the vehicle interface.
- **Algorithms and models**: Develop algorithms and fine-tune neural network models for trucking use cases.
- **Safety and standards**: Ensure safety and comply with relevant industry standards.

## Approach

We validate our work through proof-of-concept (PoC) deployments with real vehicles around the world. The target maturity of the solution is Technology Readiness Level 6 (TRL-6), which means a system demonstrated in a relevant environment.

## Technical Direction

| Stage | Target |
| --- | --- |
| Initial target | **Highway piloting, SAE Level 2+**, with an **end-to-end (E2E), vision-only** system |
| Long-term goal | **SAE Level 4** autonomous highway trucking |

A vision-only approach keeps hardware costs lower than LiDAR-based systems, and an open platform avoids vendor lock-in. These two factors are key to making autonomous trucking practical for fleet operators.
